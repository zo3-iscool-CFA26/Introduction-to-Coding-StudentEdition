## Problem 5 - Guild launch checklist

File: [week01_p5_checklist_broken.txt](week01/week01_p5_checklist_broken.txt)

**Goal:** five steps that walk a brand-new apprentice through running a Python
script.

This is a plain text file, not a program, so you cannot run it. Read it the way
a brand-new apprentice would: could you follow these steps from top to bottom
and successfully run your first script?

```text
- Open terminal
- Run python3 filename.py
- Navigate to folder
- Fix errors and rerun
- Read output
```
